# Public Release and Security Notes

This is an educational incident-response portfolio, not an operational playbook for an unapproved environment. All discovery described in the reports was limited to a student-controlled, isolated VMware lab.

## Included
- De-identified reports and summaries.
- Explanations of methodology, findings, confidence boundaries, and lessons learned.

## Excluded intentionally
- Passwords, candidate-password lists, and credential material.
- Raw event logs, response archives, screenshots, and host-side collection outputs.
- Personal email addresses, local account names, machine hostnames, and exact private lab IP addresses.

The source material remains local. Do not add raw evidence or credentials to this public repository. If a sensitive item is found in a future revision, remove it from the repository and rotate any exposed credential; deleting a file in a later commit does not remove it from Git history.
